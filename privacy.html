Privacy policy

Last updated: 30 September 2026

Who uses it. yt-automation is used only by the owner of one YouTube channel. It has no other users.

What it accesses. With the scope yt-analytics.readonly it reads, read-only, the YouTube Analytics and YouTube Reporting data of the owner's own channel: views, average percentage viewed, subscribers gained, traffic sources, audience retention, thumbnail impressions and click-through rate of the channel's videos.

How it is used. The data is used only to measure the channel's own episodes and to decide, with the owner's approval, how to improve the next ones.

Where it is kept. The data and the access token are stored only on the owner's own computer. Nothing is sold, shared or transferred to third parties, and nothing is used for advertising.

Google API Services. The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Revoking access. Access can be removed at any time at myaccount.google.com/permissions. Stored data can be deleted from the owner's computer at any time.
