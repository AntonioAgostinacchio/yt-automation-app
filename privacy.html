Privacy policy

Last updated: 13 October 2026

YouTube API Services. yt-automation uses YouTube API Services. By using it you agree to be bound by the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Who uses it. yt-automation is used only by the owner of one YouTube channel (Pursuit of Suns). It has no other users and no sign-up.

What it accesses with the owner's authorization. After the owner signs in with Google, the tool uses these scopes, only on the owner's own channel:

  • youtube.upload: to upload the channel's own videos as private and to set their thumbnails;
  • youtube.force-ssl: only to upload the captions of those videos. The tool does not delete videos and does not read, write or moderate comments or ratings;
  • yt-analytics.readonly: to read, read-only, the YouTube Analytics and Reporting data of the channel's own videos (views, average percentage viewed, subscribers gained, traffic sources, audience retention, thumbnail impressions and click-through rate).

What it accesses without authorization. With an API key, the tool reads public data that anyone can see on YouTube: titles and public statistics of the recent videos of a short list of science channels, and YouTube search results for science topics. No personal data of viewers or commenters is read.

How it is used. The channel's own data is used to publish the channel's videos and to measure how they perform, so the owner can decide how to improve the next ones. Public data of other channels is used only to understand which topics viewers are looking for. Figures the tool calculates (for example views per day) are used only inside the tool and are never presented as YouTube data.

Where it is kept and for how long. All data and the access token are stored only on the owner's own computer and its local backups.

  • Public data of other channels is refreshed from the API or deleted within 30 days (in practice after at most 28 days).
  • The channel's own analytics are kept while the owner's authorization remains valid; the tool checks the authorization at least every 30 days.
  • If the owner revokes access, the data obtained with that authorization is deleted within 30 days.

Sharing. Nothing is sold or used for advertising. Titles of public videos and the channel's own statistics may be processed by AI language models reached through OpenRouter, only to perform the functions described above. No other third party receives the data.

Cookies. This website and the tool place no cookies and store nothing on visitors' devices.

Revoking access and deleting data. Access can be removed at any time from the Google security settings page at security.google.com/settings/security/permissions. To ask for any stored data to be deleted, write to the contact below: it is deleted within 7 days.

Google API Services. The use of information received from Google APIs adheres to the Google API Services User Data Policy, including the Limited Use requirements.

Changes. Any change to this policy is published on this page with a new date.
